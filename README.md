## 📑 نبذة عامة (Project Overview)

**لوميرا (LUMYRA)** هي منصة طبية سريرية وذكية متكاملة لصحة الثدي، تجمع بين التعاطف الإنساني والصرامة الطبية العلمية. تهدف المنصة إلى القضاء على حاجز الخوف والتشخيص المتأخر لسرطان الثدي عبر توفير منظومة رقمية متصلة تربط السيدة بالطبيب المعالج وإدارة المنظومة الصحية، مدعومة بأحدث تقنيات الرؤية الحاسوبية من **Google Gemini AI** وخوارزميات تقييم المخاطر المعتمدة عالمياً (**Gail Model** و **Tyrer-Cuzick Model**).

---

## 🌸 سر التسمية (Why "LUMYRA"?)

اسم **لوميرا** مستوحى من دمج دلالي هادف:
1. **Lumière (فرنسية/لاتينية)**: تعني **النور والضياء** — نور المعرفة والاطمئنان الذي يبدد ظلام الخوف والتردد من الفحص.
2. **Amira / Mira (عربية/لاتينية)**: تعني **الأميرة، السلام، والأعجوبة** — تعبيراً عن رعاية كل سيدة بكرامة فائقة واحتواء دافئ.
3. **الهوية اللونية**: درجات الورد والبودرة الناعمة (*Soft Blush & Powder Rose*) مع العنابي الوقور (*Deep Burgundy*) لكسر برودة وجفاف ألوان المستشفيات التقليدية وإضفاء السكينة والهدوء.

## 🌟 أبرز المميزات (Key Features)

### 👩‍🦰 1. للمريضات والزائرات (Patients & Guests)
- **🌸 استبيان تقييم المخاطر الطبي الذكي**: استبيان دوري شامل من 5 خطوات سريرية يغطي التاريخ الهرموني، الإنجابي، العائلي، وفحوصات الخزعات مع حساب فوري لمخاطر الـ 5 سنوات ومخاطر مدى الحياة وكود توثيقي سريري مشفر.
- **🔬 فحص الصور الطبية بـ Gemini AI**: تحليل فوري لصور السونار والماموجرام وتقارير التحاليل مع **صمام أمان صارم** يكتشف الصور غير الطبية ويصنفها كـ `inconclusive` لمنع أي تشخيص خاطئ.
- **📍 دليل المراكز والعيادات عبر الـ GPS**: فرز تلقائي لأقرب المراكز المتخصصة (مثل مؤسسة بهية ومعهد الأورام) وعيادات الأطباء المعتمدين مع الاتصال المباشر والمسار.
- **💊 متتبع الالتزام بالدواء واليوميات**: تتبع جرعات العلاج الهرموني (مثل التاموكسيفين) ومتابعة الالتزام الدوائي وتدوين الأعراض.

### 👨‍⚕️ 2. للأطباء والاستشاريين (Doctors & Oncologists)
- **🚨 منظومة التنبيهات السريرية الذكية (Smart Alerts)**: فرز وترتيب أولويات المريضات تلقائياً (`CRITICAL`, `HIGH`, `MODERATE`) للحالات التي تستلزم خزعة عاجلة أو تراجع التزامها الدوائي.
- **🖥️ وحدة الاستعراض الإشعاعي المتقدمة (DICOM Viewer)**: عارض ماموجرام احترافي يدعم الزوايا القياسية (`L-CC`, `R-MLO`, `R-CC`, ومقارنة سابقة)، صناديق تحديد الآفات المشتبه بها (`ROI 1`)، التكبير المجهري، وعكس التباين.
- **📂 سجل الفحوصات المحفوظة**: إمكانية إدارة أرشيف الفحوصات مع **إعادة التسمية** و**الحذف**.
- **💬 المحادثة السريرية المباشرة**: تواصل فوري ومباشر مع المريضات للمتابعة والاستشارات.
- **🗺️ تسجيل العيادة على الخريطة**: إضافة ونشر بيانات عيادة الطبيب ومواعيدها لتظهر للمريضات.
- **✍️ نظام إدارة المحتوى التوعوي (CMS)**: كتابة ونشر مقالات طبية معتمدة وموثوقة.

### 🛠️ 3. لمسؤولي النظام والحوكمة (Administrative Governance)
- **📊 لوحة القيادة والإحصائيات الحية**: مؤشرات تفاعلية لأعداد المريضات والأطباء والفحوصات، مع رسم بياني شهري لحجم الأشعة.
- **🛡️ مراجعة واعتماد تراخيص الأطباء**: تدقيق بيانات الترخيص الصادر من وزارة الصحة لمنع انتحال الصفة الطبية.
- **👥 إدارة المستخدمين الشاملة**: تصفية وبحث فوري في الحسابات، مع إمكانية تعليق أو تفعيل أي حساب بلمسة واحدة.
- **🤖 المساعد الذكي للإدارة (AI Copilot)**: شات مدعوم بـ Gemini لتقديم تقارير تشغيلية وتوصيات إدارية ذكية.
- **💾 النسخ الاحتياطي وتصدير البيانات**: تصدير نسخة احتياطية منزوعة الهوية الشخصية ومطابقة لمعايير الخصوصية الطبية.

## 🏛️ المعمارية البرمجية (System Architecture)

```
LUMYRA/
├── lib/                             # تطبيق الموبايل والويب (Flutter)
│   ├── app/                         # التهيئة، الثيمات، والتوجيه (GoRouter)
│   ├── core/                        # المكونات المشتركة، شبكة الاتصال، والتصميم
│   └── features/
│       ├── auth/                    # توثيق الحسابات والتبديل اللحظي بين الأدوار
│       ├── questionnaire/           # استبيان المخاطر ونماذج Gail & Tyrer-Cuzick
│       ├── doctor_dashboard/        # عارض DICOM، التنبيهات الذكية، والشات
│       ├── admin_dashboard/         # التحليلات الحية، إدارة المستخدمين، والـ Copilot
│       └── medical_centers/         # الدليل الجغرافي والفرز التلقائي عبر GPS
└── backend/                         # الخادم الخلفي المؤسسي (NestJS)
    └── src/
        ├── modules/
        │   ├── ai/                  # محرك Gemini للرؤية الحاسوبية والدردشة الطبية
        │   ├── scans/               # معالجة وحفظ وتعديل وحذف الفحوصات
        │   ├── risk-assessment/     # نماذج ومعايير تقييم الخطورة السريرية
        │   ├── messages/            # خدمة وتدفق الرسائل السريرية المباشرة
        │   ├── doctors/             # التنبيهات السريرية وإدارة عيادات الأطباء
        │   ├── medical-centers/     # خدمة المراكز الجغرافية والمسافات
        │   ├── educational/         # نظام إدارة المحتوى التوعوي (CMS)
        │   ├── admin/               # إحصائيات المنصة، Copilot، والنسخ الاحتياطي
        │   └── users/               # إدارة المستخدمين والصلاحيات
        └── common/                  # خدمات Prisma، الأمان، وسجل التدقيق (Audit)
```

## 🛠️ التقنيات المستخدمة (Tech Stack)

| المجال | التقنية المستخدمة | الدور في المنظومة |
| :--- | :--- | :--- |
| **Frontend** | Flutter 3.x / Dart | تطبيق الموبايل (Android/iOS) والويب بتصميم متجاوب بالكامل ودعم RTL-first |
| **State Management** | Riverpod | إدارة الحالة المعمارية وتدفق البيانات بكفاءة عالية |
| **Backend API** | NestJS / TypeScript | بناء خادم خدمات مصغرة معياري وسريع وآمن |
| **Artificial Intelligence** | Google Gemini (3.5 / 3.6 Flash) | تحليل الصور والأشعات الطبية، استخراج تقارير الخطورة، و Copilot الإدارة |
| **Database & ORM** | PostgreSQL / Prisma ORM | هيكلة البيانات السريرية، سجلات التدقيق، والملفات المحفوظة |
| **Maps & Location** | Haversine Formula / GPS | حساب المسافات الجغرافية الدقيقة بين المريضة والمراكز |

## ⚡ التشغيل السريع محلياً (Quick Start)

### 1. تشغيل الخادم الخلفي (Backend)
```bash
cd backend
npm install
npm run build
npm run start
```
*سيعمل الخادم على المنفذ: `http://localhost:4000/api/v1`.*

### 2. تشغيل تطبيق الهاتف (Mobile App)
```bash
flutter pub get
flutter run
```
